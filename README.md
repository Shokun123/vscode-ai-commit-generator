## 🚀 Features

- 🧠 **Instant Git Diff Analysis:** Reads your staged files (`git add`) and determines the exact semantic category (`feat`, `fix`, `docs`, `test`, `refactor`, `chore`).
- 📝 **Conventional Commits Standard:** Formats clean, standardized commit messages used by top engineering teams worldwide.
- 📋 **Automated Release Changelog:** Groups commits by type and generates Markdown release notes in seconds.
- ⚡ **Zero Configuration:** Works out-of-the-box in any Git repository without requiring paid API keys.
- 🎨 **Multiple Formatting Styles:** Supports `angular` (`feat(auth): ...`), `gitmoji` (`✨ feat(auth): ...`), and `minimal`.

---

## 🛠️ How to Use

1. Stage your modified files in VS Code using the Source Control tab or terminal:
   ```bash
   git add .
   ```
2. Open the Command Palette (`Ctrl + Shift + P` or `Cmd + Shift + P` on macOS).
3. Select:
   - **`Git: AI Commit: Generate Commit Message from Staged Changes`**
4. The generated message will instantly populate your Git commit input box ready to be committed!
